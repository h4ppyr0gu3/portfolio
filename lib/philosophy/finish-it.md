# Finish it

Definition of Done: what a silly phrase

done is when i no longer give a fuck, this is the problem, we all are very eager to start but reluctant to finish

Nothing matters unless it is finished, you can have any number of things on the go, they are only done when they are done, start optimising to finish, even if it is a rough draft, put it in the history books, come back to it another time, it is done, it can be polished later

but it is finished, how many projects are started but not finished because they lack motivation

we are all driven by motivation when what we actually need is some discipline

there is so much to be done, finish what you started, share it, maybe someone else will be able to polish it, even if it is a piece of crap, it can still be polished at a later date
